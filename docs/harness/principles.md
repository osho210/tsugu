# Harness Principles

## MUST

MUST rules should be enforced by deterministic tools whenever possible.

## SHOULD

SHOULD rules require contextual judgment and are primarily handled by Codex.

## MAY

MAY rules are optional choices.

## Rule lifecycle

When the same review feedback appears repeatedly:

1. Determine whether a Tool can prevent it.
2. If not, determine whether Codex can detect it reliably.
3. Otherwise, keep it as Human Review.

Remove rules that are obsolete or replaced by Tool enforcement.
