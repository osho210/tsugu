# Documentation

## MUST

- Exported TypeScript declarations require TSDoc.
- TSDoc must include a meaningful summary.
- Do not duplicate TypeScript type information in documentation.
- TODO comments must reference a GitHub Issue.

## SHOULD

- Prefer explaining why over explaining what.
- Private declarations require documentation only when intent is unclear.
- Use `@param`, `@returns`, `@throws`, `@remarks`, and `@example` only when they add useful context.
